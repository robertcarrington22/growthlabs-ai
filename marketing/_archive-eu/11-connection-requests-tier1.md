# Personalized Connection Requests — First 5 Tier 1 Accounts

## Strategy
1. Visit the company LinkedIn page, find the decision maker
2. Send a personalized connection request (300 character max)
3. After they accept, send follow-up message with Revenue Health Scorecard
4. Track all in outreach-tracker.csv
